# wpAMP

Lighweight Windows Webserver

Download Apache/PHP/MySQL in ZIP format and place it in "bin" folder

## How To

1. All applications must be placed in "bin" folder.
2. All applications configuration must be ended with "_wpamp" (eg. "php_wpamp.ini").
3. pwAMP auto create configuration needed for the applications.
4. Variables for app config auto replacement:
   - {APACHE_PATH} = will be replaced with Apache path
   - {APACHE_HOST} = will be replaced with Apache host (can be configured in the wpAMP GUI)
   - {APACHE_PORT} = will be replaced with Apache port (can be configured in the wpAMP GUI)
   - {PHP_PATH} = will be replaced with selected PHP path
   - {PHP_MODULE_NAME} = will be replaced with PHP Apache module name
   - {PHP_MODULE_FILE} = will be replaced with PHP Apache module file name
   - {MYSQL_PATH} = will be replaced with selected MySQL path
   - {MYSQL_HOST} = will be replaced with server host (can be configured in the wpAMP GUI)
   - {MYSQL_PORT} = will be replaced with server port (can be configured in the wpAMP GUI)
   - {TMP_PATH} = will be replaced with tmp path
   - {WWW_PATH} = will be replaced with www path (your php files here)
